# Trybe projects

These projects were built during Trybe's web development program (turma sd-06).

This index lists public `sd-06-*` repositories that contain a branch with Paulo Cheloni's work: a branch named like `paulo-cheloni*`, or a `main-group-*` branch that includes his commits. Archived repositories were part of the search. Each description is translated from that repository's own README, and the stack comes from that README together with the dependencies on the linked branch.
